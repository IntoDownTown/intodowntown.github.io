Les douze chapitres et leur mise en pratique

Les durées incluent lecture, documentation officielle, pratique et restitution. La lecture seule ne valide pas les compétences ; conserve les preuves de tes exercices. Le cas pratique Chaîne DNS prolonge le cursus avec une répétition de migration vers Lift.
